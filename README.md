Airbnb Clone (React Native + Expo)

A mobile Airbnb UI clone built with React Native (Expo) and TypeScript. The app focuses on polished UI, navigation, and UX patterns inspired by Airbnb—think listings feed, search, filters, wishlists, and trip details—implemented with modern RN conventions.

<p align="center"> <img alt="Airbnb Clone" src="assets/app-icon.png" width="96" /> </p>
✨ Features

Modern navigation with Expo Router–style file system routes (app/ directory).

TypeScript-first codebase for safer, faster iteration.

Reusable UI components in components/ (cards, chips, headers, etc.).

Hooks for data/state (hooks/) and typed interfaces in interfaces/.

Theming & constants centralized in constants/.

Native projects (ios/, android/) generated for device builds.

Environment variables via .env (API keys, endpoints).

Folders like app/, components/, hooks/, and interfaces/ exist in the repo, indicating an Expo Router/TypeScript architecture. 

📱 Screens (high level)

Home / Explore feed

Search (dates, guests, map toggle)

Listing details (photos, amenities, price breakdown)

Wishlists / Favorites

Bookings / Trips
